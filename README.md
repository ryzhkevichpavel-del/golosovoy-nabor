# Глас

Бесплатная Windows-программа для диктовки текста голосом. Она сидит возле часов, показывает маленькую плавающую кнопку, распознаёт речь локально и вставляет текст туда, где сейчас стоит курсор.

## Что умеет

- Работает бесплатно и локально, без OpenAI API.
- Показывает компактную плавающую кнопку без лишних подписей.
- Запускается из иконки возле часов; левый клик начинает или останавливает запись.
- Горячая клавиша по умолчанию: `F8`.
- Записывает микрофон до повторного нажатия.
- Во время записи показывает таймер.
- Распознаёт речь через локальный Faster Whisper.
- Вставляет текст в активное окно через буфер обмена.
- Если вставка не нужна или не сработала, текст остаётся в буфере.
- Сохраняет историю диктовок в `Документы\Глас\История`.
- В настройках уже есть место под будущий режим OpenAI.

## Как установить готовую сборку

1. Скачайте архив релиза `Glas-portable.zip`.
2. Распакуйте его в любую удобную папку.
3. Запустите `Install.bat` или `Установить на рабочий стол.ps1`. Можно также просто запустить `Глас.exe` как переносимую версию.
4. При первом запуске программа подготовит локальную модель. Если нужно сделать это заранее, в настройках нажмите `Подготовить модель`.

При первом распознавании программа может скачать локальную модель `base`. Это бесплатно, но нужен интернет только для первого скачивания.

Важно: не переносите один `Глас.exe` отдельно от папки `_internal`. Быстрый запуск работает именно в формате папки.

## Совместимость

Целевая сборка: Windows 10/11, 64-bit. Windows 7/8, Windows on ARM и очень старые компьютеры пока не заявлены как поддерживаемые: их нужно проверять отдельно.

## Как пользоваться

1. Поставьте курсор туда, где нужно набрать текст.
2. Нажмите маленькую плавающую кнопку или клавишу `F8`.
3. Скажите фразу.
4. Нажмите кнопку или `F8` ещё раз.
5. Подождите распознавания: текст будет вставлен или скопирован в буфер.

## Модели

- `tiny` - самая быстрая, но качество заметно хуже.
- `base` - обычный режим по умолчанию: лучше баланс скорости и качества.
- `small` - лучше качество, но медленнее.
- `medium` - ещё лучше, но на слабом ноутбуке может быть слишком медленной.

## OpenAI-режим

Сейчас программа сделана как бесплатная локальная версия. Внутри уже предусмотрен отдельный провайдер распознавания, поэтому позже можно добавить режим OpenAI без переделки интерфейса, истории и вставки текста.

## Разработка

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements-dev.txt
.\.venv\Scripts\python -m pytest
.\.venv\Scripts\python -m golosovoy_nabor.app
```

Сборка переносимой версии:

```powershell
.\scripts\build_portable.ps1
```

## Приватность

В бесплатном режиме аудио распознаётся на вашем компьютере. Тексты сохраняются только в локальную папку истории. Аудиофайлы временно кладутся в локальную папку приложения.

Подробности: `PRIVACY.md`. План будущего OpenAI-режима: `docs-openai-future.md`.
