# Голосовой набор

Бесплатная Windows-программа для диктовки текста голосом. Она сидит возле часов, записывает голос по горячей клавише, распознаёт речь локально через Whisper и вставляет текст туда, где сейчас стоит курсор.

## Что умеет

- Работает бесплатно и локально, без OpenAI API.
- Запускается из иконки возле часов.
- Горячая клавиша по умолчанию: `Ctrl + Alt + Space`.
- Записывает микрофон до повторного нажатия.
- Распознаёт речь через `whisper.cpp`.
- Вставляет текст в активное окно через буфер обмена.
- Если вставка не нужна или не сработала, текст остаётся в буфере.
- Сохраняет историю диктовок в `Документы\Голосовой набор\История`.
- В настройках уже есть место под будущий режим OpenAI.

## Как установить готовую сборку

1. Скачайте архив релиза `GolosovoyNabor-portable.zip`.
2. Распакуйте его в любую удобную папку.
3. Запустите `Install.bat` или `Установить на рабочий стол.ps1`. Можно также просто запустить `Голосовой набор.exe` как переносимую версию.
4. В настройках нажмите `Скачать Whisper`, если программа не сделала это сама.

При первом распознавании программа может скачать локальный Whisper и модель `base`. Это бесплатно, но нужен интернет только для первого скачивания.

## Как пользоваться

1. Поставьте курсор туда, где нужно набрать текст.
2. Нажмите `Ctrl + Alt + Space`.
3. Скажите фразу.
4. Нажмите `Ctrl + Alt + Space` ещё раз.
5. Подождите распознавания: текст будет вставлен или скопирован в буфер.

## Модели

- `base` - самая лёгкая модель, подходит для слабых ноутбуков.
- `small` - лучше качество, но медленнее.
- `medium` - ещё лучше, но на слабом ноутбуке может быть слишком медленной.

## OpenAI-режим

Сейчас программа сделана как бесплатная локальная версия. Внутри уже предусмотрен отдельный провайдер распознавания, поэтому позже можно добавить режим OpenAI без переделки интерфейса, истории и вставки текста.

## Разработка

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements-dev.txt
.\.venv\Scripts\python -m pytest
.\.venv\Scripts\python -m golosovoy_nabor.app
```

Сборка переносимой версии:

```powershell
.\scripts\build_portable.ps1
```

## Приватность

В бесплатном режиме аудио распознаётся на вашем компьютере. Тексты сохраняются только в локальную папку истории. Аудиофайлы временно кладутся в локальную папку приложения.

Подробности: `PRIVACY.md`. План будущего OpenAI-режима: `docs-openai-future.md`.
