# История изменений

## 0.1.0 - 2026-05-31

- Первая публичная версия.
- Бесплатное локальное распознавание через whisper.cpp.
- Иконка возле часов.
- Горячая клавиша `Ctrl + Alt + Space`.
- Запись микрофона до повторного нажатия.
- Вставка текста в активное окно через буфер обмена.
- Сохранение истории диктовок в `Документы\Голосовой набор\История`.
- Окно истории и окно настроек.
- Переносимая сборка для Windows.
- Подготовленная архитектура для будущего OpenAI-режима.

## 0.1.1 - 2026-05-31

- Добавлена компактная плавающая кнопка без пиксельного микрофона и технических подписей.
- Кнопка перетаскивается целиком: короткий клик включает запись, перенос не запускает запись случайно.
- Левый клик по иконке возле часов теперь запускает или останавливает запись.
- Горячая клавиша по умолчанию изменена на `F8`.
- Для `F8` добавлена системная регистрация горячей клавиши Windows.
- Во время записи показывается таймер, во время распознавания - спокойный индикатор обработки.
- Убрано мигающее чёрное окно статуса.
- Русский язык включён по умолчанию.
- Бесплатное локальное распознавание переведено на Faster Whisper с постоянной загрузкой модели в памяти.
- Короткая тестовая русская фраза после прогрева распознана примерно за 1.8 секунды.
- Модель `base` оставлена по умолчанию ради нормального качества; `tiny` доступна вручную как быстрый, но менее точный режим.

## 0.1.2 - 2026-05-31

- Плавающая кнопка переведена на нативное Windows-окно с нормальной прозрачностью и сглаженными краями.
- Красный цвет полностью убран из состояний кнопки: запись теперь показывается графитовой капсулой с белым стоп-квадратом и таймером.
- Белые состояния сделаны ближе к выбранному дизайн-референсу: шире, мягче, с аккуратной тенью и без технических подписей.
- Кнопку можно перетаскивать за неё саму, без отдельной ручки переноса.
- Прогрев Faster Whisper запускается сразу при старте приложения, чтобы первый короткий диктант меньше ждал загрузку модели.

## 0.1.3 - 2026-05-31

- Таймер на чёрной кнопке записи выровнен по реальному центру цифр, а не по внутренним отступам шрифта.
