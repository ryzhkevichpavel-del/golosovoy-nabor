# История изменений

## 0.1.7 - 2026-06-01

- Исправлен сбой длинных записей: в portable-сборку добавлены внутренние данные `faster_whisper`, включая VAD-модель.
- Если VAD-фильтр тишины недоступен или падает, Voxa больше не теряет запись, а повторяет распознавание без этого фильтра.
- Установщик теперь полностью заменяет внутреннюю папку приложения, а не вкладывает новую сборку внутрь старой.
- Добавлен тест на восстановление распознавания после ошибки VAD.

## 0.1.6 - 2026-05-31

- Продукт переименован в Voxa: английское название, английский exe, ярлыки и архив.
- При старте записи кнопка сразу переходит в состояние подготовки, а в режим записи - только когда микрофон уже начал отдавать звук.
- Анимация распознавания переведена на плавную перерисовку внутри нативной кнопки, без скачущего 8 FPS индикатора.
- Плавающая кнопка снова принудительно включается при обновлении старых настроек, чтобы её нельзя было случайно потерять.
- Добавлен тихий локальный лог ошибок и этапов записи без сохранения полного текста диктовки.
- Вставка текста на Windows переведена на более прямой системный Ctrl+V с запасным вариантом через старый механизм.
- Модель `small` проверена и убрана из обычного выбора: на целевом ноутбуке она слишком медленная.

## 0.1.5 - 2026-05-31

- Рабочее продуктовое название изменено на «Глас», без потери старых настроек.
- Сборка переведена из одного большого exe в быстрый формат папкой, чтобы окно и плавающая кнопка появлялись быстрее.
- Правый клик по плавающей кнопке теперь открывает маленькое меню, а не большое окно настроек.
- Для плавающей кнопки добавлены нормальный курсор-рука и мягкая реакция на наведение.
- Локальное распознавание сильнее закреплено за русской диктовкой и теперь отсекает паузы в записи.
- В README явно указано, что готовую сборку можно установить с GitHub Releases, а целевая совместимость сейчас Windows 10/11 x64.

## 0.1.0 - 2026-05-31

- Первая публичная версия.
- Бесплатное локальное распознавание через whisper.cpp.
- Иконка возле часов.
- Горячая клавиша `Ctrl + Alt + Space`.
- Запись микрофона до повторного нажатия.
- Вставка текста в активное окно через буфер обмена.
- Сохранение истории диктовок в `Документы\Голосовой набор\История`.
- Окно истории и окно настроек.
- Переносимая сборка для Windows.
- Подготовленная архитектура для будущего OpenAI-режима.

## 0.1.1 - 2026-05-31

- Добавлена компактная плавающая кнопка без пиксельного микрофона и технических подписей.
- Кнопка перетаскивается целиком: короткий клик включает запись, перенос не запускает запись случайно.
- Левый клик по иконке возле часов теперь запускает или останавливает запись.
- Горячая клавиша по умолчанию изменена на `F8`.
- Для `F8` добавлена системная регистрация горячей клавиши Windows.
- Во время записи показывается таймер, во время распознавания - спокойный индикатор обработки.
- Убрано мигающее чёрное окно статуса.
- Русский язык включён по умолчанию.
- Бесплатное локальное распознавание переведено на Faster Whisper с постоянной загрузкой модели в памяти.
- Короткая тестовая русская фраза после прогрева распознана примерно за 1.8 секунды.
- Модель `base` оставлена по умолчанию ради нормального качества; `tiny` доступна вручную как быстрый, но менее точный режим.

## 0.1.2 - 2026-05-31

- Плавающая кнопка переведена на нативное Windows-окно с нормальной прозрачностью и сглаженными краями.
- Красный цвет полностью убран из состояний кнопки: запись теперь показывается графитовой капсулой с белым стоп-квадратом и таймером.
- Белые состояния сделаны ближе к выбранному дизайн-референсу: шире, мягче, с аккуратной тенью и без технических подписей.
- Кнопку можно перетаскивать за неё саму, без отдельной ручки переноса.
- Прогрев Faster Whisper запускается сразу при старте приложения, чтобы первый короткий диктант меньше ждал загрузку модели.

## 0.1.3 - 2026-05-31

- Таймер на чёрной кнопке записи выровнен по реальному центру цифр, а не по внутренним отступам шрифта.

## 0.1.4 - 2026-05-31

- Убрана светлая верхняя дуга с белой плавающей кнопки, чтобы она выглядела чище.
- Тени плавающей кнопки сделаны мягче и больше не обрезаются ровной линией по краю прозрачного окна.
