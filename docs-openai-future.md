# Будущий режим OpenAI

Сейчас программа работает бесплатно и локально через `whisper.cpp`.

Чтобы позже добавить OpenAI-режим, нужно:

1. Добавить новый класс распознавания рядом с `WhisperCppTranscriber`.
2. Читать API-ключ из переменной среды `OPENAI_API_KEY`.
3. Использовать модель из настройки `openai_model`.
4. Добавить переключатель провайдера в окно настроек.
5. Оставить историю, запись микрофона и вставку текста без изменений.

Такой путь специально заложен в настройках:

- `provider`
- `openai_enabled`
- `openai_model`
- `openai_api_key_env`
